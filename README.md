# 📚 Anotações de Carreira

Resumos de livros técnicos, anotações de referência rápida e material base para artigos nas áreas de testes, web, Linux, Python, planejamento e outras.

---

## 🎯 Objetivo

Centralizar o conhecimento adquirido em leituras técnicas de forma organizada, criando uma base de consulta rápida para o dia a dia e um ponto de partida para a produção de conteúdo e artigos.

---

## 📂 Estrutura

```
anotacoes-de-carreira/
└── livros/
    ├── testes/
    │   ├── livros/
    │   └── notas/
    ├── web/
    │   ├── livros/
    │   └── notas/
    ├── linux/
    ├── python/
    ├── planejamento/
    └── ...
```

Cada pasta de tema contém subpastas por livro com:

- **Resumo geral**: visão macro do conteúdo;
- **Anotações por capítulo**: pontos principais, exemplos e insights;
- **Referências rápidas**: comandos, padrões ou conceitos para consulta posterior.
