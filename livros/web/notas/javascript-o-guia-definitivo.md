## 2 Estrutura léxica

### 2.1 Conjunto de caracteres

#### 2.1.1 Diferenciação de maiúsculas e minúsculas

JavaScript é uma linguagem sensível a maiúsculas e minúsculas (case-sensitive).

Isso exige que palavras-chave (como while), variáveis e nomes de funções sejam escritos de forma consistente; por exemplo, online e Online são nomes distintos.

Em atributos HTML de eventos, como onclick, o JavaScript normalmente utiliza letras minúsculas, apesar de o HTML não fazer essa diferenciação.

#### 2.1.2 Espaço em branco, quebras de linha e caracteres de controle de formato

A linguagem ignora espaços e, na maioria das vezes, quebras de linha entre os sinais (tokens) do código.

Essa característica permite o uso livre de espaços e indentação para tornar o programa mais organizado e legível.

Além do espaço comum (\u0020), são reconhecidos como espaço em branco: tabulação (\u0009), tabulação vertical (\u000B), avanço de página (\u000C), espaço não separável (\u00A0) e marca de ordem de byte (\uFEFF).

Os términos de linha reconhecidos incluem avanço de linha (\u000A), retorno (\u000D), separador de linha (\u2028) e separador de parágrafo (\u2029).

#### 2.1.3 Sequências de escape Unicode

JavaScript utiliza sequências de escape começando com \u seguidas de quatro dígitos hexadecimais para representar caracteres Unicode arbitrariamente.

Essas sequências podem ser usadas em strings literais, expressões regulares e identificadores (como \u03c0 para representar o caractere π).

Essa funcionalidade é útil para garantir a compatibilidade em sistemas que não suportam a entrada direta de todo o conjunto Unicode.

#### 2.1.4 Normalização

O Unicode permite diferentes codificações para o mesmo caractere, mas o JavaScript não realiza normalização automática de strings, identificadores ou expressões regulares.

A linguagem opera sob a premissa de que o código-fonte já foi devidamente normalizado antes de ser processado pelo interpretador.

### 2.3 Literais

Um literal é um valor de dados que aparece diretamente em um programa. Os valores seguintes são todos literais:

```javascript
12                    // O número doze
1.2                   // O número um ponto dois
"hello world"         // Uma string de texto
'Hi'                  // Outra string
true                  // Um valor booleano
false                 // O outro valor booleano
/javascript/gi        // Uma "expressão regular" literal (para comparação de padrões)
null                  // Ausência de um objeto
{ x:1, y:2 }          // Um inicializador de objeto
[1,2,3,4,5]           // Um inicializador de array
```

### 2.4 Identificadores e palavras reservadas

Um identificador é simplesmente um nome utilizado em JavaScript para nomear variáveis, funções e fornecer rótulos para determinados laços de código.

Regras de nomenclatura:

- Deve começar obrigatoriamente com uma letra, um sublinhado (_) ou um cifrão ($);
- Os caracteres subsequentes podem incluir letras, dígitos, sublinhados ou cifrões;
- Dígitos não são permitidos como o primeiro caractere, facilitando para o JavaScript a distinção entre identificadores e números.

Embora o uso de letras e dígitos ASCII seja comum por portabilidade, o JavaScript permite identificadores com letras e dígitos de todo o conjunto Unicode, possibilitando o uso de outros idiomas e símbolos matemáticos (ex: var sí = true; ou π = 3.14;).

O JavaScript reserva identificadores específicos que fazem parte da sintaxe da linguagem (como if, while, function, return) e que não podem ser usados como nomes de variáveis ou funções.

`Identificadores válidos`

```javascript
// Começando com letra, _ ou $
let nomeUsuario = "João";
let _contador = 10;
let $valorTotal = 150.50;

// Caracteres subsequentes (podem conter números)
let usuario2 = "Maria";
let item_01_final = true;

// Uso de Unicode (acentos e símbolos matemáticos)
let pontuação = 95;      // Letras com acento são permitidas
const π = 3.14159;       // Símbolos matemáticos válidos
let sí = true;           // Outros idiomas
```

`Identificadores Inválidos`

```javascript
// let 1lugar = "Ouro";  // Erro: Não pode começar com dígito
// let meu-nome = "Ana"; // Erro: O hífen não é permitido (interpretado como subtração)
// let var = 10;         // Erro: 'var' é uma PALAVRA RESERVADA
```

`Palavras reservadas`

```javascript
function calcularMedia(nota1, nota2) {     // 'function' é reservada para função
    let soma = nota1 + nota2;              // 'let' é reservada para declarar
    if (soma > 10) {                       // 'if' é reservada para controle
        return soma / 2;                   // 'return' é reservada para saída
    }
}
```

### 2.5 Pontos e vírgulas opcionais

Uso básico: JavaScript utiliza o ponto e vírgula (;) para separar instruções, tornando o significado do código claro e evitando que o fim de uma instrução seja confundido com o início da próxima.

O ponto e vírgula pode ser omitido quando:

- As instruções estão em linhas separadas;
- A instrução está no final do programa;
- O próximo sinal no código é uma chave de fechamento (}).

## 3 Tipos, valores e variáveis

### 3.1 Números

#### 3.1.1 Literais inteiros

São números sem casas decimais. O JavaScript permite escrevê-los em diferentes bases numéricas:

`Decimal`

Base 10, o padrão do dia a dia.

```javascript
42
1000
-7
```

`Hexadecimal`

Base 16, começam com `0x` ou `0X`. Muito usados para cores e endereços de memória.
  
```javascript
0xff   // 255 em decimal
0xFF   // 255 em decimal (maiúsculo também funciona)
```

`Binário`

Base 2, começam com `0b` ou `0B`.
 
```javascript
0b1010  // 10 em decimal
0B1111  // 15 em decimal
```

`Octal`

Base 8, começam com `0o` ou `0O`.
 
```javascript
0o377   // 255 em decimal
0o10    // 8 em decimal
```

#### 3.1.2 Literais em ponto flutuante

`Formato padrão`

Usa-se o ponto para separar o inteiro da fração.
 
```javascript
3.14   // pi aproximado
0.5    // metade
.33    // o zero antes do ponto é opcional
-2.75  // número negativo com fração
```
 
`Notação exponencial (científica)`

Usada para números muito grandes ou muito pequenos. Segue o formato `[número]e[expoente]`.
 
```javascript
6.02e23   // 6.02 × 10^23 (número de Avogadro)
1.47e-4   // 0.000147
1e10      // 10000000000
```

##### Math.

Além dos operadores básicos, JavaScript oferece operações matemáticas mais complexas por meio de funções e constantes do objeto `Math`:

`Arredondamento`

```javascript
Math.round(0.6)  // 1.0 — arredonda para o inteiro mais próximo
Math.ceil(0.6)   // 1.0 — arredonda para cima
Math.floor(0.6)  // 0.0 — arredonda para baixo
```

`Valores e comparações`

```javascript
Math.abs(-5)     // 5 — valor absoluto
Math.max(x,y,z)  // retorna o maior argumento
Math.min(x,y,z)  // retorna o menor argumento
Math.random()    // número pseudoaleatório x, onde 0 <= x < 1.0
```

`Potências e raízes`

```javascript
Math.pow(2, 53)   // 9007199254740992 — 2 elevado à potência 53
Math.sqrt(3)      // raiz quadrada de 3
Math.pow(3, 1/3)  // raiz cúbica de 3
```

`Constantes`

```javascript
Math.PI  // π — circunferência / diâmetro
Math.E   // e — base do logaritmo natural
```

`Trigonometria`

```javascript
Math.sin(0)  // seno — também: Math.cos, Math.atan, etc.
```

`Logaritmos`

```javascript
Math.log(10)              // logaritmo natural de 10
Math.log(100) / Math.LN10 // logaritmo base 10 de 100
Math.log(512) / Math.LN2  // logaritmo base 2 de 512
Math.exp(3)               // Math.E ao cubo
```

##### Infinity e NaN

Divisão por zero não é um erro em JavaScript, ela retorna valores especiais.

`Infinity`

Resultado de divisões por zero ou estouro de valor.

```javascript
Infinity                 // variável global com infinito positivo
Number.POSITIVE_INFINITY // mesmo valor, somente leitura
1 / 0                    // Infinity
Number.MAX_VALUE + 1     // Infinity
```

`-Infinity`

Infinito negativo.

```javascript
Number.NEGATIVE_INFINITY // somente leitura
-Infinity
-1 / 0                   // -Infinity
-Number.MAX_VALUE - 1    // -Infinity
```

`NaN`

Not a Number: resultado indefinido ou operação inválida.

```javascript
NaN                      // variável global
Number.NaN               // mesmo valor, somente leitura
0 / 0                    // NaN
Infinity / Infinity      // NaN
Math.sqrt(-1)            // NaN
"texto" * 2              // NaN (operando não numérico)
```

`Zero negativo`

Estouro negativo resulta em -0.

```javascript
Number.MIN_VALUE / 2     // 0 (estouro positivo)
-Number.MIN_VALUE / 2    // -0
-1 / Infinity            // -0
-0
```

#### 3.1.4 Ponto flutuante binário e erros de arredondamento

`NaN`

Não é igual a nenhum valor, nem a si mesmo. Use `isNaN()` para verificar.

```javascript
x == NaN        // sempre falso, nunca use isso
x != x          // true somente se x for NaN

isNaN(NaN)      // true
isNaN("texto")  // true  (não numérico também retorna true)
isFinite(x)     // true se x não for NaN, Infinity ou -Infinity
```

`Zero negativo`  

Zero negativo é comparado como igual ao zero positivo, exceto quando usado como divisor.

```javascript
var zero = 0    // zero normal
var negz = -0   // zero negativo

zero === negz       // => true  — são considerados iguais
1/zero === 1/negz   // => false — Infinity !== -Infinity
```

JavaScript usa o formato IEEE-754, que representa números em binário. Frações decimais comuns como `0.1` **não podem ser representadas com exatidão**, o que pode causar resultados inesperados.

```javascript
var x = .3 - .2   // trinta centavos menos vinte centavos
var y = .2 - .1   // vinte centavos menos dez centavos

x == y    // false — os dois valores não são os mesmos!
x == .1   // false — .3 - .2 não é exatamente 0.1
y == .1   // true  — .2 - .1 é igual a 0.1
```

> Para cálculos financeiros, evite aritmética com decimais diretamente. Prefira trabalhar com inteiros (ex: centavos) e converter ao exibir.

#### 3.1.5 Datas e horas

JavaScript inclui a construtora `Date()` para criar objetos que representam datas e horas.

`Criando datas`

```javascript
var then   = new Date(2010, 0, 1)             // 1º dia do 1º mês de 2010
var later  = new Date(2010, 0, 1, 17, 10, 30) // mesmo dia, às 17:10:30 (hora local)
var now    = new Date()                       // data e hora atuais
var elapsed = now - then                      // subtração: intervalo em milissegundos
```

`Obtendo componentes da data`

```javascript
later.getFullYear()   // 2010
later.getMonth()      // 0   — meses com base em zero (0 = janeiro)
later.getDate()       // 1   — dias com base em um
later.getDay()        // 5   — dia da semana (0 = domingo, 5 = sexta-feira)
later.getHours()      // 17  — 5 da tarde, hora local
later.getUTCHours()   // horas em UTC — depende do fuso horário
```

`Formatando a saída`

```javascript
later.toString()            // "Sexta-feira, 01 de janeiro de 2010, 17:10:30 GMT-0800 (PST)"
later.toUTCString()         // "Sábado, 02 de janeiro de 2010, 01:10:30 GMT"
later.toLocaleDateString()  // "01/01/2010"
later.toLocaleTimeString()  // "05:10:30 PM"
later.toISOString()         // "2010-01-02T01:10:30.000Z" — somente ES5+
```
